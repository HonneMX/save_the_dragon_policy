1. Общие положения

Настоящая Политика описывает, какие данные могут обрабатываться при использовании мобильного приложения «Как подружиться с драконом» (далее — Приложение), распространяемого через магазины приложений (в том числе RuStore).

Используя Приложение, вы подтверждаете, что ознакомились с этой Политикой. Если у вас есть вопросы — напишите на s_man_17@mail.ru.

2. Какие данные мы не запрашиваем

Приложение не требует регистрации, ФИО, номера телефона, адреса и иных персональных данных для начала игры. Вы можете играть без создания аккаунта.

3. Данные на устройстве

Для сохранения прогресса Приложение хранит локально на устройстве игровые данные (например: прогресс кампании, настройки звука, внутриигровые ресурсы). Эти данные не предназначены для идентификации личности.

4. Аналитика (Яндекс AppMetrica)

Для улучшения Приложения мы можем использовать сервис Яндекс AppMetrica. Он помогает понимать, как играют пользователи, где возникают сложности и какие функции востребованы.

Могут обрабатываться обезличенные / технические сведения, например:

  • факт установки и запуска Приложения;
  • события прогресса (старт / победа / поражение раундов и боссов);
  • выборы в игровых офферах (продолжить, воскрешение, жизни, удвоение награды);
  • технические события рекламы (показ / награда / ошибка);
  • сведения об устройстве и приложении в объёме, необходимом SDK аналитики.

Подробнее о обработке данных Яндексом: условия AppMetrica.

5. Реклама (Яндекс РСЯ)

В Приложении может показываться реклама через Яндекс Рекламную сеть (РСЯ), в том числе rewarded-ролики (за просмотр можно получить внутриигровую награду).

Рекламный SDK может получать технические данные, необходимые для показа и измерения рекламы (в объёме, предусмотренном Яндексом). Подробнее: условия Mobile Ads SDK.

6. Передача данных третьим лицам

Мы не продаём персональные данные пользователей. Технические и аналитические данные могут обрабатываться провайдерами SDK (Яндекс) в соответствии с их политиками и договорённостями.

7. Дети

Приложение рассчитано на широкую аудиторию (казуальная игра). Мы сознательно не запрашиваем данные, позволяющие установить личность ребёнка. Если вы родитель / законный представитель и считаете, что данные ребёнка обрабатываются некорректно — напишите на s_man_17@mail.ru.

8. Изменения Политики

Мы можем обновлять эту Политику. Актуальная версия всегда доступна по адресу этой страницы. Дата публикации указана в начале документа.
